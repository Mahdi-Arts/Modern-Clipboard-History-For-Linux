# Archived workflow patches / پچ‌های آرشیوشدهٔ ورک‌فلو

Historical, superseded patches. They transform workflows into states that
predate the 2026-08-21 release-readiness pass (legacy names, third-party
Rust action). **Do not apply them** — use
[`../hardened-ci-workflows.patch`](../hardened-ci-workflows.patch), which
is regenerated from the live, fixed pipelines.

آماده‌سازی انتشار ۲۰۲۶-۰۸-۲۱‌اند. اعمال نکنید؛ پچ بازتولیدشدهٔ اصلی را
